# Financial Modeling & Investment Analysis – West Ridge North

## Project Description

This project focused on building a **dynamic financial model in Excel** to evaluate the financial viability of acquiring and potentially selling the **West Ridge North property** for STREIT, A Real Estate Investment Trust. I used historical financial data from the property’s **income statement** to forecast future financial performance and assess investment profitability.

The model integrated **financial forecasting, capital budgeting techniques, and time value of money principles** to provide a structured framework for real estate investment decision-making.

---

# Objectives

The primary objective of this project was to:

* Forecast **future income, expenses, and net income** for the property
* Evaluate the **investment attractiveness** of the acquisition
* Analyze **different financial scenarios and assumptions**
* Apply **capital budgeting techniques** to guide investment decisions
* Determine whether the investment meets **the required return thresholds**

---

# Financial Modeling Approach

## 1. Income Statement Forecasting

Historical financial data from the property’s **income statement** was used to build a structured financial model that projects future performance.

The model forecasts:

* Rental income
* Operating expenses
* Net operating income (NOI)
* Net income
* Future property value

These projections helped estimate the **long-term profitability and sustainability of the investment**.

---

## 2. Dynamic Financial Modeling

The model was designed using **dynamic Excel features**, allowing key assumptions to automatically update financial outcomes.

Key variables included:

* Acquisition price
* Expected rental income
* Operating expenses
* Discount rate
* Holding period
* Sale price

This dynamic structure allowed the model to easily adjust to **changing market conditions or investment assumptions**.

# Scenario and Sensitivity Analysis

To enhance the robustness of the analysis, **Excel’s What-If Analysis toolkit** was applied.

### Scenario Manager

Different investment scenarios were created to evaluate how changes in key variables affected financial outcomes.

Examples included:

* Optimistic scenario (higher rental income)
* Base case scenario
* Conservative scenario (higher operating expenses)

This allowed the investors to **compare potential outcomes under different economic conditions**.

---

### Goal Seek

Goal Seek was used to determine critical values such as:

* The **required sale price** to achieve a target return
* The **minimum rental income required** to meet profitability goals

This tool helped investors identify the **conditions needed for investment success**.

---

### Data Tables

Data Tables were used to analyze **how changes in multiple variables impact investment returns**, allowing quick sensitivity analysis across different assumptions.

---

# Time Value of Money (TVM) Analysis

Because **money today is worth more than money in the future**, the model incorporated time value of money principles to properly evaluate the investment.

Key metrics analyzed included:

* **Present Value (PV)** – the current value of future cash flows
* **Future Value (FV)** – the value of the investment at the end of the holding period(10 years)
* **Return on Investment (ROI)** – profitability relative to investment cost

This ensured investment decisions were made with a **long-term financial perspective**.

---

# Capital Budgeting Analysis

To determine whether the acquisition was financially viable, the model applied key **capital budgeting techniques** such as:.

### Net Present Value (NPV)

NPV calculates the present value of all future cash flows generated by the property, discounted at the required rate of return.

Interpretation:

* **NPV > 0 → Investment adds value**
* **NPV < 0 → Investment destroys value**

---

### Internal Rate of Return (IRR)

IRR represents the **annualized rate of return generated by the investment**.

It helps determine whether the project meets the investor’s **minimum required return**.

Decision rule:

* **If IRR > Required Return → Accept the investment**
* **If IRR < Required Return → Reject the investment**
